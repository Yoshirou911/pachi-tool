# PACHI TOOL Mobile

iPhoneのSafariからホーム画面へ追加して使う、オフライン対応の期待値フィールドツールです。

## iPhoneへのインストール

1. 公開URLをSafariで開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. 「Webアプリとして開く」をオンにして追加する。
5. 一度オンラインで起動し、早見表が表示されたことを確認する。

以降はホーム画面のアイコンから起動でき、期待値表・10秒判定・資金管理・候補台・実戦記録はオフラインで利用できます。

端末データの消去や機種変更に備え、設定画面から定期的にバックアップを書き出してください。
